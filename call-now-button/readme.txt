The click-to-call button for WordPress since 2013. Add a call button in under a minute. No code, mobile and desktop, with click tracking.

== Description ==

Call Now Button puts a floating call button on your website. On a phone, one tap starts the call. On a desktop, it's a standard click-to-call link that opens in the visitor's calling app. Either way, nobody has to hunt for your contact page or copy a number by hand.

It has been doing exactly that since 2013, on more than 200,000 websites.

### Set it up in under a minute

Install, enable the button, type your phone number, save. There is no account to create, no code to paste, and nothing more to configure before it works.

From there you can make it yours:

* **Label it:** Leave the label empty for a clean, circular phone button or add text. The text can sit in a bar across the top or bottom of the screen or in a bubble beside the round button.
* **Color it:** Pick your own button and icon colors.
* **Place it:** Choose from 8 preset screen positions or spread the button across the full width of the top or bottom of the screen.
* **Size it:** Use one slider to set the button size and another to place the button behind other page elements when something else, such as a cookie notice, needs to sit on top.
* **Show it where it belongs:** Enter post and page IDs to show the button only on those pages or to exclude those pages.
* **Show it to the right devices:** Choose mobile only, desktop only, or both.
* **Measure it:** Send clicks to Google Analytics or fire a Google Ads conversion tag so that a call counts as a conversion. Using Google Tag Manager instead? There's a guide for that.

All of the above is free and works without an account.

== Installation ==

1. From your WordPress Dashboard go to 'Plugins' > 'Add new' and search for 'Call Now Button'.
2. Click 'Install Now' under the title of the Call Now Button plugin
3. Click activate
4. Go to 'Call Now Button' from the sidebar, check the box to activate the button and enter your phone number.
5. Click 'Save' and you're done!

Or:

1. Upload the `call-now-button`-folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Call Now Button' from the sidebar, check the box to activate the button and enter your phone number.
4. Click 'Save' and your Call Now Button is live!


== Frequently Asked Questions ==

= Is it free? What do I get without an account? =

Yes. Without an account you get one call button with labels, your own colors, all 8 screen positions, button size and layering controls, include/exclude by post and page ID, mobile/desktop control, Google Analytics click tracking and Google Ads conversion tracking. No account, no signup, no code. Connecting to a free NowButtons.com account is still completely free and adds more buttons and more action types (see the plan list in the Description).

= Does it work on desktop? =

Yes. You choose whether the button shows on mobile only, desktop only, or both. On mobile a tap starts the call directly. On desktop the button is a standard tel: link, the same kind used across the web. The visitor's computer opens it in whichever app handles calls, such as Teams, a softphone or a phone-linked app like Phone Link on Windows or Handoff on a Mac.

= Does it slow down my site? =

No. Without an account, no external service is contacted at all. The button is rendered by your own site and nothing is fetched from us. If you connect to an account, your button configuration is served from a CDN, loaded asynchronously and cached in WordPress rather than fetched on every page view.

= Does it work with Elementor, Divi, WooCommerce and other themes and page builders? =

Yes. The button is added to the page independently of your theme or page builder, so it works alongside all of them. The only requirement is a responsive theme. If you have to zoom in to read your site on a phone, the button will not behave correctly.

= Is it GDPR compliant? Does it set cookies? =

Without a NowButtons.com account the plugin sets no cookies, collects no personal data and makes no external requests. The button is rendered by your own site. Nothing about your visitors reaches us and nothing is loaded from our servers.

Two things to be aware of:

* If you enable Google Analytics click tracking or Google Ads conversion tracking, those are your own tags under your own consent policy. The plugin sends the event; it does not install the tracking scripts.
* If you connect a NowButtons.com account, your button configuration is stored on and served from our servers, and requests identify your site URL, WordPress version and PHP version. No visitor data is involved. See our [Privacy statement](https://nowbuttons.com/legal/privacy/).

Anonymous error and usage reporting is off by default and never runs on your visitors' pages.

= What data goes to NowButtons when I connect to your cloud service? =

When you create an account, the email address you enter and your site's domain are sent to us. After that, your button configuration is stored on and served from our servers, and requests identify your WordPress version, PHP version and site URL. Nothing is sent before you connect. See the [Privacy statement](https://nowbuttons.com/legal/privacy/) and [Terms & Conditions](https://nowbuttons.com/legal/terms/).

= Where can I enter my phone number? =

You'll find Call Now Button in your sidebar. Click on it to reveal the button configuration page.

= Do I have to add a country code to my phone number? =

You don't have to, but we recommend that you do to increase your options internationally.

= Do I start the number with + or 00? =

In most countries you'll be fine using either but there are some exceptions. To be on the safe side we recommend using the plus sign.

= Can I add text to the button? =

Yes, it is possible to add text to your button. You can choose to show the text inside the full width button across the bottom or top of the screen. It's also possible to add a text bubble next to the circular button. This works for all placements with the exception of the center button positions at the top and bottom of the screen.

= Can I change the appearance of the Call Now Button? =

Yes! You can easily change the color of the button and make it sit in any of the 8 preset locations across the screen of a phone. You also have the option to spread it out over the full bottom or top of the screen.

= I only want to show the button on a few pages. Is that possible? =

Yes, you can enter the IDs of posts and pages you wish to include or exclude.

= I don't see the button on my website. Why? =

First step is to check if the button is enabled - this is the first checkbox on the configuration page.

Next thing is to make sure that your theme is responsive. Responsive means that the website adapts to the size of the screen it's being viewed on. Simply put, if you need to zoom in to be able to read the text of your website on your mobile phone, the plugin will not work.

Last thing to check is if you have a caching plugin installed. Caching plugins make your website faster by showing a copy of your website instead of the actual website. As a consequence you will not see the Call Now Button because the copy was made before the button was installed. To fix this, go to your cache plugin settings page and empty the cache (sometimes called flush or purge). After doing this you should see the button. Do the same thing each time you make changes to the button.

= I only see the button on some pages of my website =

You have a caching plugin active on your website and the cached pages are showing an older version of your website. Delete/empty the cache and reload the pages.

Another option could be that you have set the Call Now Button to only appear on specific pages. Go into the Call Now Button configuration, open the Presentation tab and check that the field next to Limit appearance is empty.

= I need way more flexibility! Isn't there a PRO version that I can use? =

Yes, you can connect the plugin to our cloud service. That already enables a bunch of extras for free. From there you can upgrade to PRO. Read the plan list in the Description to see what's included in PRO, or check out [NowButtons.com](https://nowbuttons.com/).
